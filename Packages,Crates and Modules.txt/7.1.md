# 7.1 — Packages and Crates

> **Mental Model**
>
> `Package` → `Crate` → `Crate Root` → `Modules`

---

## 📦 Package

**Package = poore Rust project ka container.**

```text
my-project/
├── Cargo.toml
└── src/
```

- `Cargo.toml` → package ki configuration
- At least **1 crate** hona zaroori hai
- Maximum **1 library crate**
- Multiple **binary crates** possible hain

---

## 🦀 Crate

**Crate = Rust compiler ka compilation unit.**

| Type | Purpose | Crate Root |
|---|---|---|
| **Binary** | Executable program | `src/main.rs` |
| **Library** | Reusable functionality | `src/lib.rs` |

### Binary Crate

```rust
fn main() {
    println!("Hello");
}
```

→ Executable program banta hai, isliye `main()` hota hai.

### Library Crate

→ Reusable functionality provide karta hai.

Example:

```rust
use rand::Rng;
```

→ `rand` ek library crate hai.

---

## 🌱 Crate Root

**Crate Root = woh file jahan se Rust crate ko start karta hai.**

```text
src/main.rs → Binary crate ka root
src/lib.rs  → Library crate ka root
```

> **Crate Root se hi crate ka module tree start hota hai.**

---

## 📦 Package with Multiple Crates

```text
my-project/
├── Cargo.toml
└── src/
    ├── main.rs
    ├── lib.rs
    └── bin/
        ├── server.rs
        └── client.rs
```

```text
Package
├── Binary  → main.rs
├── Library → lib.rs
├── Binary  → server.rs
└── Binary  → client.rs
```

`src/bin/*.rs` ki **har file ek separate binary crate** hoti hai.
