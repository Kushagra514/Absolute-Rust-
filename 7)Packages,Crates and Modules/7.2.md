# 7.2 — Control Scope and Privacy with Modules

> **Mental Model**
>
> `mod` → organize code  
> `pub` → make code accessible  
> `path` → find code  
> `use` → shortcut for a path

---

## 🌳 Module Tree

Rust code ek **module tree** mein organized hota hai.

Har crate ka root module implicitly `crate` hota hai.

```text
crate
└── front_of_house
    ├── hosting
    │   ├── add_to_waitlist
    │   └── seat_at_table
    │
    └── serving
        ├── take_order
        ├── serve_order
        └── take_payment
```

- **Parent** → jis module ke andar doosra module hai
- **Child** → parent ke andar wala module
- **Siblings** → same parent ke andar wale modules
- **Root** → `crate`

---

## 📦 Modules

Module declare karne ke liye `mod` use hota hai:

```rust
mod front_of_house {
    mod hosting {
        fn add_to_waitlist() {}
    }
}
```

Modules ke andar:

- functions
- structs
- enums
- constants
- traits
- other modules

rakh sakte hain.

### Why Modules?

Related code ko group karke code ko:

- organized
- readable
- easy to navigate
- privacy-controlled

rakhne ke liye.

---

## 📁 Modules in Separate Files

Module ko same file mein define karna zaroori nahi.

```rust
pub mod garden;
```

> **`mod garden;` module ko declare karta hai.**
>
> Rust phir `garden` module ka code conventional locations mein dhundta hai.

Possible locations:

```text
src/garden.rs
```

or

```text
src/garden/mod.rs
```

Ya module directly inline bhi ho sakta hai:

```rust
mod garden {
    // module code
}
```

### Submodules

Agar `garden.rs` mein:

```rust
pub mod vegetables;
```

hai, toh Rust `vegetables` module ko normally yahan dhundega:

```text
src/garden/vegetables.rs
```

or

```text
src/garden/vegetables/mod.rs
```

Example:

```text
src/
├── main.rs
├── garden.rs
└── garden/
    └── vegetables.rs
```

Module tree:

```text
crate
└── garden
    └── vegetables
```

## 🔗 Paths

Module ke kisi item ko access karne ke liye **path** use karte hain.

Example:

```text
crate::garden::vegetables::Asparagus
```

Read it as:

```text
crate
  ↓
garden
  ↓
vegetables
  ↓
Asparagus
```

### Absolute Path

Crate root se start hota hai:

```rust
crate::garden::vegetables::Asparagus
```

`crate` = current crate ka root.

### Relative Path

Current location se start kar sakte hain:

```rust
garden::vegetables::Asparagus
```

> **Path = code ka address.**

## 🔐 Privacy

Rust mein modules aur items **private by default** hote hain.

```rust
mod garden {
    mod vegetables {
        struct Asparagus {}
    }
}
```

External code directly inhe access nahi kar sakta.

Public banana ho toh `pub` use karo:

```rust
pub mod garden {
    pub mod vegetables {
        pub struct Asparagus {}
    }
}
```

### Important

Sirf outer module ko `pub` karna enough nahi hai:

```rust
pub mod garden {
    mod vegetables {
        pub struct Asparagus {}
    }
}
```

Yahan:

```text
garden     → public
vegetables → private
Asparagus  → public
```

`Asparagus` tak bahar se pahunchne ke liye `vegetables` bhi public hona chahiye.

```text
pub garden
    ↓
pub vegetables
    ↓
pub Asparagus
```

> **Public item tak pahunchne ke liye path ke required modules bhi accessible hone chahiye.**

## ⚡ `use` — Path ka Shortcut

Agar baar-baar ye path use karna ho:

```rust
crate::garden::vegetables::Asparagus
```

toh:

```rust
use crate::garden::vegetables::Asparagus;
```

Ab directly:

```rust
let plant = Asparagus {};
```

likh sakte hain.

```text
Full path
crate::garden::vegetables::Asparagus
              ↓
             use
              ↓
Shortcut
Asparagus
```

> **`use` item ko move ya copy nahi karta. Sirf ek shorter path/name available karata hai.**

### `mod` vs `use`

`use` kisi module ko create nahi karta.

Agar `mod garden;` hata dein:

```rust
use crate::garden::vegetables::Asparagus;
```

Rust error dega:

> **`garden` module exist hi nahi karta.**

Kyunki `mod garden;` hi Rust ko batata hai ki `garden` naam ka module crate ka part hai.

```text
mod garden;
    ↓
"garden module exist karta hai"

use crate::garden::vegetables::Asparagus;
    ↓
"existing module ke Asparagus ka shortcut banao"
```

> **`mod` → module ko declare karta hai**  
> **`use` → existing item ka shortcut banata hai**

## 🧩 Complete Example

### File Structure

```text
src/
├── main.rs
├── garden.rs
└── garden/
    └── vegetables.rs
```

### `main.rs`

```rust
use crate::garden::vegetables::Asparagus;

pub mod garden;

fn main() {
    let plant = Asparagus {};
    println!("I'm growing {plant:?}!");
}
```

### `garden.rs`

```rust
pub mod vegetables;
```

### `vegetables.rs`

```rust
#[derive(Debug)]
pub struct Asparagus {}
```

Module tree:

```text
crate
└── garden
    └── vegetables
        └── Asparagus
```

`use` ki wajah se:

```rust
Asparagus
```

likh sakte hain instead of:

```rust
crate::garden::vegetables::Asparagus
```

## 🧠 Cheat Sheet

| Concept | Meaning |
|---|---|
| `mod` | Module declare karo |
| `pub` | Public/accessibile banao |
| `crate::` | Crate root se path start karo |
| `use` | Path ka shortcut banao |
| Parent | Containing module |
| Child | Nested module |
| Siblings | Same parent wale modules |

### Final Mental Model

```text
📦 Crate
│
└── 🌳 Module Tree
    │
    ├── mod   → organize
    ├── pub   → expose
    ├── path  → locate
    └── use   → shortcut
```
